# Calcul de la Somme des Valeurs d'Étalonnage

Ce projet contient un script Node.js qui calcule la somme des valeurs d'étalonnage en extrayant les chiffres d'un fichier texte. L'algorithme identifie le premier et le dernier chiffre de chaque ligne, les combine, et les additionne pour obtenir une somme totale.

## Description

Le script parcourt chaque ligne du fichier Document.txt, extrait les chiffres présents, et calcule une valeur pour chaque ligne basée sur la concaténation du premier et du dernier chiffre. Ces valeurs sont ensuite additionnées pour produire un résultat final.

# Résultat 
La somme totale des valeurs d'étalonnage est : 33740
